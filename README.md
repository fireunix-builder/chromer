# Chromer

Public build and release repository for Chromer on Apple Silicon.

This repository is intended for build workflows, release notes, and downloadable application packages. The application source code is maintained separately and is not published here.

## Repository scope

- Build and packaging workflows may be stored here.
- Source code must come from an authorized private source during a build.
- Application source, private profiles, credentials, and private test data must not be committed or included in public artifacts or logs.

Build workflows and release packages have not been published yet.

Repository visibility does not grant an open-source license to the application.
